🔍 Vulnerability Scanning with Tenable — Windows 10 VM
TenableAzure VMsDISA STIGVulnerability Management
Configured and executed an advanced network vulnerability scan using Tenable Vulnerability Management against an intentionally misconfigured Windows 10 virtual machine hosted in Microsoft Azure. Applied DISA STIG compliance audit policies and analyzed the full results.
  • Provisioned a Windows 10 VM in Azure and intentionally introduced misconfigurations (weak credentials, disabled firewall, open NSG) to simulate a vulnerable endpoint
  • Configured an Advanced Network Scan template in Tenable with credentialed scanning, TCP port scanning, and DISA Microsoft Windows 10 STIG compliance audits
  • Launched the scan and analyzed results — reviewed vulnerabilities by plugin, compliance audit findings, and remediation recommendations
  • Documented the full workflow from VM setup through scan execution and results analysis
🏢 The Cyber Range Internship 🔧 Tenable · Azure · Windows 10 · DISA STIG
⚙️ STIG Remediation Automation with PowerShell — WN10-AU-000500
PowerShellDISA STIGTenableAzure VMsCompliance
Identified a failing DISA STIG compliance check on a Windows 10 Azure VM, manually remediated the finding, validated the fix, then automated the remediation using a PowerShell script — following a full professional vulnerability remediation lifecycle.
  • Ran a Tenable STIG compliance scan targeting DISA Windows 10 STIG v3r1 and identified the failing control WN10-AU-000500 (audit policy configuration)
  • Researched the STIG requirement and manually applied the remediation, then rescanned to confirm the fix was successful
  • Reverted the manual fix and rescanned to demonstrate the failure state — proving before/after validation methodology
  • Developed a PowerShell script to automate the STIG remediation, tested it against the VM, and confirmed compliance via rescan
  • Published the PowerShell script to GitHub as a reusable compliance automation tool
